Approach

I’ll be analyzing time-series data for at least two separate items and use window functions to compute:

  • Year-to-Date (YTD) average

  • Six-day moving average

I would focus not just on calculating averages, but on applying window functions correctly within grouped time-series data.

Dataset Selection

I will use a time-series dataset containing daily closing prices for at least two financial instruments (e.g., two stocks or cryptocurrencies) starting from January 1, 2022.

The dataset will include:

  • date

  • item (stock or cryptocurrency name/symbol)

  • closing_price

This structure allows grouping by item and ordering by date which are both required for window functions.

Data Preparation

Before applying window functions, I will:

  1. Ensure the date column is stored as a proper date type.

  2. Sort the dataset by item and date.

  3. Verify no duplicate dates per item.

  4. Handle missing dates or values if necessary.

The data will be grouped by item before calculating rolling or cumulative metrics.

Year-to-Date (YTD) Average

The YTD average represents the cumulative average price for each item from January 1 of the current year up to each specific date.

Using window logic:

  • Partition by item

  • Order by date

  • Use a cumulative window frame from the start of the year to the current row

Six-Day Moving Average The six-day moving average calculates the average closing price over the current day and the previous five days.

Using window logic:

  • Partition by item

  • Order by date

  • Use a rolling window frame of 6 rows (current row + 5 preceding rows)

For the first five days (where fewer than six observations exist), the result will either:

  • Be NA, or use partial windows (depending on implementation choice)

Anticipated Challenges

1. Ordering and Grouping

Window functions depend heavily on correct ordering. Any sorting errors will produce incorrect rolling averages.

2. Year Boundaries

If multiple years are included, YTD must reset each January 1. This requires partitioning by both item and year.

#Now calculate YTD average using the cummean function in dplyr
stock_ytd <- stock_data %>%
  group_by(stock, year(date)) %>%
  arrange(date) %>%
  mutate(
    ytd_avg = cummean(close)
  )
